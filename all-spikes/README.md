# all-spikes

One subdirectory per research idea, per `voila.md`: *"Keep all research artifacts for the
selected idea inside its dedicated subdirectory under `all-spikes/`."*

Naming: `NN-short-slug` (e.g. `01-rollout-error-growth`). Numbered so the order in which
ideas were attempted stays visible — including the ones that were abandoned. Abandoned
spikes stay in the tree with a NOTES.md saying why; that record is part of the honest
research process and feeds the paper appendix.

See `CLAUDE.md` at the repo root for the per-spike directory layout.
